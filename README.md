# :house_with_garden: Willowbend Subdivision

A modern, responsive community website for **Willowbend Subdivision**, located in Brgy. Pinagkuartelan, Pandi, Bulacan, Philippines. This site serves as the official public-facing resource for residents and visitors — covering subdivision information, rules and regulations, HOA officers, contact details, FAQs, and a photo gallery.

## :book: About the Project
 
Willowbend Subdivision's website was built to give residents easy access to community information — from HOA rules and officer directories to emergency hotlines and frequently asked questions — while giving the subdivision a professional, welcoming online presence.
 
The project started as a set of static HTML pages and is being progressively converted into a full **React** component architecture, built section-by-section for maintainability and reusability.
 
---
 
## :hammer_and_wrench: Built With
 
This project is built using:
 
- :atom_symbol: **React** — component-based UI library
- :zap: **Vite** — fast build tool and development server
- :art: **Tailwind CSS v4** — utility-first CSS framework (CSS-first configuration)
- :compass: **React Router DOM** — client-side routing (`NavLink`, `BrowserRouter`)
- :framed_picture: **Hugeicons** (`@hugeicons/core-free-icons` + `@hugeicons/react`) — icon system
- :sparkles: **AOS (Animate On Scroll)** — scroll-based animations
